# Резервные копии

English: [../backups.md](../backups.md)

Netoryx копирует собственную базу данных: пользователей, подписки, платежи, настройки, тексты. Панели VPN (3x-ui и
другие) он не копирует, их нужно сохранять их собственными средствами. Аккаунты на панелях можно восстановить из базы
Netoryx, потому что источник истины - база.

## Автоматические копии

Включены по умолчанию (`BACKUP_ENABLED=true`), каждый день в `BACKUP_TIME` (04:00 по `TZ`). Каждая копия пишется в
`BACKUP_DIR` (`data/backups`, то есть `/app/data/backups` в томе `app-data` контейнера приложения); хранятся последние
`BACKUP_KEEP` файлов (7), а сам файл отправляется в чат Telegram `BACKUP_CHAT_ID` (по умолчанию первому администратору).

Задайте `BACKUP_PASSWORD`, чтобы шифровать копии (вывод ключа scrypt, AES-256-GCM). **Сделайте это**: копия содержит данные
клиентов и зашифрованные секреты и проходит через Telegram. Храните пароль отдельно от копий; потерянный пароль делает
копию нечитаемой.

Два формата, оба сжаты gzip:

- логический (`.jsonl.gz`): каждая таблица строками JSON. Работает с SQLite, PostgreSQL и MySQL и восстанавливается в любую
  из них, поэтому подходит и для переезда между базами;
- снимок SQLite (`.sqlite.gz`): быстрая согласованная копия для установки на SQLite.

Зашифрованные файлы заканчиваются на `.enc`.

## Сделать копию сейчас

```bash
sudo netoryx backup
```

или раздел **Backups** в веб-админке.

## Восстановление

Восстановление **заменяет все текущие данные**. Нужны файл копии и, если он зашифрован, пароль.

```bash
cd /opt/netoryx
docker compose cp /path/to/<backup file> app:/app/data/backups/
docker compose stop app
docker compose run --rm app /app/.venv/bin/python -m app restore /app/data/backups/<backup file> --yes --password '<password>'
docker compose up -d app
```

`--password` можно опустить, если `BACKUP_PASSWORD` задан в `.env`. Восстановление выполняется одной транзакцией; после него
приложение приводит панели к восстановленному состоянию. На новом сервере сначала выполните установку, затем восстановление.

## Хорошие привычки

- Копируйте резервные копии за пределы сервера (копия в Telegram подходит; локальный том не переживёт потерю сервера).
- Делайте ручную копию перед каждым обновлением.
- Один раз проверьте восстановление на тестовой машине.
- Храните копию `/opt/netoryx/.env`: в нём `SECRET_KEY` и пароль базы данных.
