# Переезд с другого бота

English: [../migrating.md](../migrating.md).

## С Bedolaga (Remnawave)

Импорт переносит пользователей и их подписки из резервной копии бота Bedolaga. Клиенты продолжают работать: если панель
Remnawave, которой они пользуются, подключена к Netoryx, каждая подписка забирает существующий аккаунт клиента в панели,
поэтому ссылка в его приложении остаётся прежней.

Что переносится:

- пользователи с Telegram ID: имя, язык, баланс (записью в журнале операций), кто кого пригласил;
- у каждого пользователя подписка с самой поздней датой окончания: дата, статус (активна, истекла, приостановлена),
  признак пробного периода, лимит устройств и лимит трафика.

Что не переносится: история платежей, промокоды, тарифы, кампании, аккаунты только с e-mail (без Telegram ID) и
удалённые пользователи. Тарифы и цены настраиваются в Netoryx заново.

### Шаги

1. Сделайте резервную копию в админке Bedolaga и скачайте `.tar.gz`. Подойдёт и отдельный файл
   `database.sql`, `database.json` или `database.sqlite` из неё.
2. Установите Netoryx (`--panel none`, если панель Remnawave остаётся на своём месте) и подключите эту панель в
   веб-админке (**Серверы**). Запомните её номер.
3. Скопируйте копию на сервер и сначала посчитайте (ничего не меняется):

   ```bash
   sudo netoryx import-bedolaga /root/backup.tar.gz --panel-id 1
   ```

   В отчёте видно, сколько пользователей и подписок будет перенесено, у скольких ссылка сохранится (`links_kept`) и
   скольким понадобится новая (`new_links`: для них не нашёлся аккаунт в панели).
4. Импорт:

   ```bash
   sudo netoryx import-bedolaga /root/backup.tar.gz --panel-id 1 --apply
   ```

5. Переключите бота: впишите тот же токен в Netoryx (`BOT_TOKEN` в `/opt/netoryx/.env`, затем
   `sudo netoryx restart app`) и остановите старый бот, чтобы клиенты нашли свою подписку в том же чате.

Повторный запуск переносит только тех, кого здесь ещё нет: уже существующие пользователи никогда не меняются. Без
`--panel-id` подписки получат новые аккаунты в панели при следующей синхронизации, и клиентам нужно будет добавить новую
ссылку из бота.
