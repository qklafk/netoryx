# Форматы подписки

English: [../subscriptions.md](../subscriptions.md).

Личная ссылка `/sub/<token>` (и `/sub/<token>/loc/<id>` для одной локации) отвечает в одном из двух форматов в
зависимости от приложения:

| Приложение | Формат |
|---|---|
| Happ, v2RayTun | **JSON-подписка**: массив полных конфигов Xray, по одному на сервер, и конфиг «Авто» |
| Остальные (INCY, Hiddify, Streisand, v2rayNG, ...) | Обычный base64-список ссылок |

Приложение определяется по `User-Agent`. Оба формата строятся из одних данных: серверы, названия, параметры
Reality и заголовки ответа (название профиля, трафик, интервал обновления, объявление, лимит устройств)
совпадают. Истёкшая или приостановленная подписка в любом формате даёт одну запись-заглушку.

## Что внутри JSON

В каждом конфиге: локальные входящие SOCKS (`127.0.0.1:10808`) и HTTP (`127.0.0.1:10809`) с определением
трафика, сервер как исходящий `proxy`, исходящие `direct` и `block`, маршрутизация и DNS. Название записи
находится в поле `remarks`.

При двух и более серверах первым идёт конфиг «Авто» (`<название бренда> · Авто`): все серверы стоят за
балансировщиком `leastPing`, а наблюдатель раз в десять минут проверяет `https://www.google.com/generate_204`;
запасной вариант - первый сервер. С одним сервером записи «Авто» нет.

Маршрутизация, срабатывает первое подходящее правило:

1. DNS-запросы (к российскому резолверу напрямую, остальные через VPN);
2. домены из `SUB_JSON_PROXY_DOMAINS` через VPN;
3. частные и локальные сети напрямую;
4. российские домены напрямую (`.ru`, `.su`, `.рф` и короткий список крупных сервисов на других доменах, плюс
   `SUB_JSON_DIRECT_DOMAINS`);
5. всё остальное через VPN (или через балансировщик «Авто»).

Имена, подходящие под прямые правила, разрешает `77.88.8.8`, остальные - `1.1.1.1` через VPN. Используются только
явные правила по доменам, без файлов geo-данных, поэтому результат не зависит от комплекта приложения.

## Настройки

| Настройка | По умолчанию | Смысл |
|---|---|---|
| `SUB_JSON_ENABLED` | `true` | Отдавать JSON в Happ и v2RayTun. `false`: всем список ссылок. |
| `SUB_JSON_AUTO` | `true` | Добавлять конфиг «Авто» при двух и более серверах. |
| `SUB_JSON_DIRECT_RU` | `true` | Российские домены напрямую. `false`: всё через VPN и один DNS. |
| `SUB_JSON_DIRECT_DOMAINS` | пусто | Дополнительные домены напрямую, через запятую или с новой строки. |
| `SUB_JSON_PROXY_DOMAINS` | пусто | Домены, которые всегда идут через VPN, даже если подходят под прямое правило (например, российский сайт, недоступный из России). |

Записи доменов: `example.com` (домен и поддомены) или с префиксом Xray: `full:host.example`, `keyword:...`,
`regexp:...`. Настройки доступны и в веб-админке в разделе ссылки подписки.

## Примечания

- Приложения передают импортированный JSON в Xray без изменений, поэтому их собственный профиль маршрутизации к
  нему не применяется; действуют только правила выше.
- Записи, которые Xray не может выразить точно (например, HTTP-обфускация TCP), остаются только в base64-списке.
- Для Reality сохраняется компактный hello (`REALITY_COMPACT_HELLO`) через отпечаток Firefox.
