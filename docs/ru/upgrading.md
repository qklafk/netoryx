# Обновление

English: [../upgrading.md](../upgrading.md)

Netoryx использует семантическое версионирование с пред-релизной меткой на время беты (`0.9.0-beta`). Перед обновлением
прочитайте [CHANGELOG.md](../../CHANGELOG.md), особенно при переходе между минорными версиями.

## Обычное обновление

```bash
sudo netoryx backup
sudo netoryx update
```

`netoryx update` загружает новый релиз в `/opt/netoryx` и пересобирает и перезапускает **только контейнер приложения**
(`docker compose up -d --build --no-deps app`). Миграции базы выполняются автоматически при старте (`AUTO_MIGRATE=true`).
VPN-сессии не прерываются: VPN, `edge` и `caddy` не затрагиваются. На небольшом сервере пересборка занимает пару минут; бот
недоступен несколько секунд, пока запускается новый контейнер.

Если релиз меняет контейнеры `edge`, `caddy`, панели или прокси для Telegram (об этом скажет обновление), перезапустите их
осознанно, в спокойный час и по одному, например `docker compose up -d --no-deps edge`. Это рвёт открытые соединения;
большинство клиентов переподключаются, некоторым нужно выключить и включить VPN.

## Ручное обновление

```bash
cd /opt/netoryx
git pull            # или распакуйте новый релиз поверх каталога
docker compose up -d --build --no-deps app
docker compose logs -f app
```

Ваши `.env`, `deploy/haproxy/sni.map` и `deploy/caddy-sites/*.caddy` относятся к конкретному серверу; сравните
`.env.example` со своим `.env`, чтобы увидеть новые параметры.

## Проверка после обновления

```bash
netoryx status
curl -s https://<domain>/healthz
```

В админке раздел **System** показывает версию и фоновые задачи, а все панели в **Panels** должны быть исправны.

## Откат

Миграции автоматически не откатываются. Чтобы вернуться, восстановите копию, сделанную перед обновлением
([backups.md](backups.md)), и переключитесь на предыдущий релиз. Поэтому копия делается первой.

## Перенос базы данных

Переход с SQLite на PostgreSQL (или обратно) выполняется через логическую копию: сделайте копию, укажите в `DATABASE_URL`
новую пустую базу и восстановите ([backups.md](backups.md)).
