# Ссылка доступа к Telegram (подписка «только Telegram»)

English: [../telegram-only.md](../telegram-only.md).

Одна общая ссылка, которая помогает людям **попасть в Telegram** (а значит, и к вашему боту), когда он у них не
открывается: **через VPN идёт только Telegram**, всё остальное устройство подключает напрямую. Её можно публиковать и
пересылать: разместить на сайте, в чатах и каналах, передавать из уст в уста. Она заменяет прокси для Telegram из
прежних версий ([telegram-proxy.md](telegram-proxy.md), он остаётся как необязательная устаревшая функция).

Это не тариф и не привязано к пользователю. Все, у кого есть ссылка, пользуются одним и тем же подключением.

## Чем делиться

Делитесь **адресом страницы**, `https://<ваш домен>/tg`. Он не меняется. Страница оформлена названием вашего сервиса
(`BRAND_NAME`, а не названием проекта), на русском или английском в зависимости от языка браузера посетителя:

- в двух строках объясняет, что это («Telegram будет работать через это подключение; остальные приложения и сайты
  работают как обычно»);
- определяет устройство и показывает для него кнопку скачивания **Happ** (остальные платформы - в один тап);
- содержит кнопку **«Добавить в Happ»**, которая импортирует подписку одним нажатием;
- показывает ссылку подписки с кнопкой копирования и QR-кодом, а также ручные шаги («Добавить подписку по ссылке»).

Страница всегда показывает **актуальную** ссылку подписки (`https://<ваш домен>/sub/tg/<токен>`), поэтому смена токена
не требует нового объявления. Она ничего не загружает с других сайтов, без трекеров и не кэшируется.

Администраторы найдут оба адреса в админ-меню бота (**Доступ к Telegram**) и в веб-админке (**Инфраструктура → Доступ
к Telegram**). Установщик печатает их с QR-кодом в конце, а бот присылает владельцу один раз, когда первый сервер готов.

## Смена ссылки

Если ссылка разошлась слишком широко, нажмите **Новая ссылка** (в боте или веб-админке). Выпускаются новый токен
подписки и новые ключи подключения: старая ссылка и ключи внутри уже импортированных конфигов перестают работать. Адрес
страницы остаётся прежним и сразу показывает новую ссылку, но тем, кто импортировал старую, придётся добавить её заново.

## Как это обеспечивается

Ограничение стоит на сервере, а не только в конфиге клиента, поэтому ссылку нельзя использовать как обычный VPN.

- На каждой подходящей панели 3x-ui есть один отдельный клиент `tg-only` в VLESS-инбаунде (Reality или TLS). Его id
  создаётся один раз и хранится в базе (при выпуске новой ссылки создаётся новый).
- Бот добавляет в шаблон Xray панели три правила перед всеми остальными (сразу после служебного правила API панели):
  1. `tg-only` + адреса Telegram → `direct`;
  2. `tg-only` + домены Telegram → `direct`;
  3. `tg-only` → `blocked`.

  Адреса - опубликованный Telegram список (<https://core.telegram.org/resources/cidr.txt>, лежит в
  `app/services/tg_only_data.py`; скачивания во время работы нет). Правила помечены `tg-only-*`; бот трогает только
  их, держит их первыми даже рядом с блокировкой рекламы и выходом для YouTube и переписывает шаблон только при
  изменении (Xray перезапускается один раз).
- Определение домена (sniffing) на инбаунде подменяет адрес назначения (`routeOnly` выключен): соединение с именем
  Telegram в TLS-рукопожатии действительно идёт в Telegram, поэтому подставить это имя и попасть на другой адрес нельзя.
- Порядок действий: сначала ставятся правила, потом создаётся клиент, а сервер попадает в подписку только после того, как
  получилось и то и другое. Панель, которую не удалось обновить, не предлагается.
- Когда сервер перестаёт подходить (страна исключена, панель отключена, функция выключена), сначала удаляется клиент,
  а потом правила.

Конфиг клиента (`/sub/tg/<токен>`) отправляет адреса и домены Telegram в VPN, а всё остальное - напрямую. При двух и
более серверах используется балансировщик `leastPing`; он проверяет задержку обращением к `telegram.org`, который серверы
разрешают. Reality использует тот же компактный ClientHello, что и основная подписка (`REALITY_COMPACT_HELLO`).

## Ограничение трафика

Раз ссылка публичная, можно ограничить, сколько она пропускает:

- `TG_ONLY_MONTHLY_LIMIT_GB` (по умолчанию `0`, без лимита): общий трафик общего клиента на каждом сервере, сбрасывается
  раз в месяц (UTC). Это лимит трафика клиента в 3x-ui, он применяется через API панели **без перезапуска Xray**. Когда
  клиент на сервере исчерпал лимит, панель отключает его до следующего сброса.
- `TG_ONLY_DAILY_ALERT_GB` (по умолчанию `50`, `0` - выключено): администраторы получают сообщение, если общий клиент за
  сутки передал больше этого объёма, не чаще раза в сутки, чтобы злоупотребление ссылкой не прошло незамеченным.

## Какие серверы предлагаются

Сервер предлагается, если выполнено всё:

- панель активна и это **3x-ui**, **Remnawave**, **Marzban**, **PasarGuard** или **Marzneshin** (см. ниже);
- на 3x-ui: есть активный VLESS-инбаунд с Reality или TLS и хотя бы одно активное стандартное подключение;
- **страна** локации сервера (у остальных панелей - заданной для панели локации) не входит в
  `TG_ONLY_EXCLUDED_COUNTRIES`.

Страна берётся из флага локации (🇩🇪 → `DE`). Исключены по умолчанию `RU,BY,CN,IR,KP,TM,VN`: страны, где Telegram
заблокирован или ограничен, поэтому «только Telegram» с выходом там не заработал бы. Локация без флага страны (например,
глобус 🌍) **не предлагается**, пока не включён `TG_ONLY_ALLOW_UNKNOWN_COUNTRY`. Установщик определяет страну сервера по
его IP и ставит флаг первой локации; для добавленного вручную сервера поставьте флаг на его локации. Экраны админки
показывают, какие серверы не предлагаются и почему.

## Поддерживаемые приложения

| Приложение | Результат |
| --- | --- |
| Happ, v2RayTun | Конфиг Xray JSON |
| Любое другое (другие VPN-приложения) | Короткий текст о том, что ссылке нужен Happ или v2RayTun |

Другим приложениям отдаётся текст, а не ссылки на серверы, намеренно: серверы отказывают во всём, кроме Telegram, и
обычный VPN-клиент, импортировав их, просто остался бы без интернета. Для отладки `?format=json` принудительно отдаёт
JSON.

## Настройки

Настройки на лету: веб-админка → Настройки, группа «Доступ к Telegram».

| Настройка | По умолчанию | Назначение |
| --- | --- | --- |
| `TG_ONLY_ENABLED` | `true` | Главный выключатель. Выключено: страница отвечает 404, клиент и правила удаляются с серверов. |
| `TG_ONLY_EXCLUDED_COUNTRIES` | `RU,BY,CN,IR,KP,TM,VN` | Коды стран через запятую, серверы которых не предлагаются. |
| `TG_ONLY_ALLOW_UNKNOWN_COUNTRY` | `false` | Предлагать и серверы, у локации которых нет флага страны. |
| `TG_ONLY_MONTHLY_LIMIT_GB` | `0` | Месячный лимит трафика общего клиента на сервер (0 - без лимита). |
| `TG_ONLY_DAILY_ALERT_GB` | `50` | Оповещать администраторов при суточном трафике выше этого (0 - выключено). |

## Ограничения

- Серверы Hiddify не предлагаются: у них нет API для маршрутизации по клиенту.
- Поддерживаемые панели и как это работает: на **3x-ui** бот правит шаблон Xray. На **Remnawave**, **Marzban**,
  **PasarGuard** и **Marzneshin** бот создаёт пользователя `tgonly` (он выключен, пока нет его правил) и добавляет те же
  три правила в конфигурацию Xray через API панели: профили конфигурации сквадов пользователя (Remnawave),
  `/api/core/config` (Marzban), ядра (PasarGuard) или конфиг Xray каждой включённой ноды (Marzneshin). Правила
  сопоставляются с именем, под которым панель передаёт этого пользователя в Xray. Для Marzban нужно ядро Xray 24.10.16
  или новее (в том числе на нодах): его имена нельзя сопоставить точно; на более старом ядре будет ошибка, ничего не
  создаётся. Изменение конфига ядра один раз перезапускает Xray на этой панели, как и любая правка. Ссылки клиента
  берутся у самой панели, поэтому у инбаунда должен быть хост.
- Пока нет готового сервера, страница отвечает `503` с короткой понятной надписью; когда функция выключена - `404`.
- Список адресов Telegram может измениться; обновите `app/services/tg_only_data.py` по странице выше.
- Сервер с публичным адресом-ретранслятором (подключение вида «relay») используется как настроено; страна проверяется
  по локации инбаунда, а не ретранслятора.
- Одна ссылка на установку; трафик всех, кто ей пользуется, считается вместе.
- Тексты страницы есть на русском и английском; для других языков показывается английский.
- Чтобы поставить флаг, установщик спрашивает у публичного GeoIP-сервиса (`ipinfo.io`, затем `ipapi.co`) страну по IP
  самого сервера. Если не получилось, флаг остаётся 🌍, и его нужно поставить в веб-админке.
